# 清空环境（本地模型）· Photoshop 插件使用说明

## 它是什么
一个精简的 PS 面板插件：把当前文档交给你**本机的 ComfyUI**（公开模型 FLUX.2 klein 9B）做"清场"，
结果作为**新图层**放回文档。**不登录、不联网、不花点数、不用任何加密模型。**

## 前置条件（只需一次）
1. 后端（ComfyUI 便携版 / 整合包）已经装好 —— 插件**自己会去找它**
2. 启动服务：面板里点【启动 ComfyUI】，或双击桌面「启动 ComfyUI」，或后端目录里的 `start_comfy.bat`
3. 面板状态显示"ComfyUI 已就绪"即可开工

### 后端目录（重点）
- 面板底部有【后端目录】输入框 + 【应用】【自动查找】两个按钮。
- 安装脚本会把本机实际路径写进 `main.js` 的 `COMFY_DIR_DEFAULT`；**就算没写成功、或事后挪了文件夹**，
  插件运行时也会自己找：① localStorage 记住的 → ② 代码里的默认值 → ③ 从插件自身位置往上找 4 层
  → ④ 扫各盘常见位置（先扫 Photoshop 所在的盘；根目录候选名 + 名字像 `browser/下载/软件/ai/comfy/清空/便携` 的目录往下 3 层）。
- 找到后写进 `localStorage`（键 `cleanbg.comfyDir`），下次直接命中；面板里改完点【应用】立即生效。
- 判据只有一个：这个文件夹里有没有 `start_comfy.bat`。
- 找不到时面板会用红字提示"请点【自动查找】或手动填写"，不会再给出写死的错误路径。

## 使用步骤
1. 打开要处理的图片
2. 改提示词（已预填一段通用清场词）
3. 选【生成规模】和【步数】
4. 点 **▶ 清空环境** —— 下方**进度条**会实时显示阶段和已用时间
   （加载模型 → 采样 1/4、2/4… → 4 倍放大 → 还原尺寸 → 颜色匹配 → 保存）
5. 结果自动置入为名为「清空环境」的新图层
6. **自己用蒙版擦掉不想改的地方**（推荐用法）

**有选区时**：结果图层会自动带蒙版，只改选区内的区域。

## 两个后端按钮 / 自动关闭
| 行为 | 说明 |
|---|---|
| **启动 ComfyUI**（按钮） | **只有你点它才会启动**，插件绝不会自己把后端拉起来。只用 `shell.openPath(原生 Windows 路径)` 一种方式：`fs.getEntryWithUrl` 是**存储** API 不是启动 API（拿它启动必然报 `Could not find an entry of …`），`openExternal("file:///…")` 自 Ps 22.5 起被禁（`file scheme is not supported`）—— 这两种注定失败却排在前面，只会产生误导性报错。调用前先自己判断 `start_comfy.bat` 存在，并把 `openPath` 的返回值（成功 = 空字符串、失败 = 错误文案）原样写进日志 |
| **关闭 ComfyUI**（按钮） | 优先调用后端自带的关闭接口优雅退出（干净释放显存），失败时兜底跑 `stop_comfy.bat` |
| **关闭 Photoshop** | 后端的看门狗会检测到 PS 退出，**自动关闭后端**（约 5 秒内） |
| 手动兜底（永远可用） | 双击桌面「启动 ComfyUI」快捷方式，或后端目录里的 `start_comfy.bat` / `stop_comfy.bat` |

后端额外装了一个极小的自定义节点 `custom_nodes\cleanbg_control`，只提供两个接口：
`GET /cleanbg/ping`（探活）和 `POST /cleanbg/shutdown`（自杀式退出）。不参与任何生成流程。

> 注意：`backend/` 里的脚本（.bat / .vbs）**必须保持纯 ASCII 内容** —— 中文会被 cmd/wscript 按 GBK 解析而破坏脚本。

## 参数建议
| 参数 | 说明 |
|---|---|
| 生成规模 标准（2.9MP，约 2048 长边） | 默认，冷启动约 55-65 秒；快档 35 秒，精细档 2 分钟 |
| 步数 4 | FLUX.2 klein 的推荐值；6 步细节略好（+30 秒） |
| 提示词 | **最关键的参数**，见下 |

> 生成规模是"模型出图规模"，跟文档实际像素无关。**最终输出一定会还原到你文档的原像素尺寸**（6048×4032 的图就出 6048×4032）。

## 画质是怎么保证的
1. **尺寸**：不问 Photoshop 要尺寸，改由 ComfyUI 自己读源图真实像素
   （踩过的坑：300DPI 文档下 PS 按"点"返回宽度，6048px 会变成 1448，结果缩小 4.17 倍）
2. **清晰度**：模型出图后用 **4 倍放大模型**（4x-UltraSharp）补细节，再还原到文档像素尺寸。
   实测输出锐度为原图的 **114%～165%**
3. **颜色**：用 **ColorMatch（mkl 强度 1.0）**把输出的色彩统计拉回原图，
   实测平均 RGB 偏差 <0.4、对比度为原图的 95%

## 提示词写法（重要）
效果**完全靠提示词**，写得越具体越好：

```
移除画面背景中的所有路人、观众与摄影器材（灯架、柔光箱、三脚架、反光板、摄影包），
移除地面杂物与电线；严格保持人物的面部、发型、服装、饰品、姿态与原始构图完全不变；
被移除的区域用周围背景的纹理、透视关系与光照智能补全，过渡自然、无修补痕迹；
保持原有色调、明暗关系与画面噪点一致，不改变整体风格。
```

- 想清得狠一点：加"清除地面上的所有标记胶带与展台拆除痕迹"
- 人少但构图要保留：强调"保留背景建筑/墙面结构与原有透视"
- 效果太"重"：把提示词缩短，只留"移除背景中的路人与器材，其余保持不变"

## 不满意怎么办
1. 结果在独立图层上 —— **用蒙版擦掉不想要的部分**（最常见）
2. 换提示词重跑（每次都会生成新图层，可以叠加对比）
3. 不够锐/不够细 → 生成规模调到"精细"，或步数调到 6
4. 过于锐利/有 AI 味 → 换更温和的放大模型

## 出问题怎么排查
- 面板日志区会逐步打印：导出 → 提交 → 生成 → 置入，哪一步失败就写在哪一步
- 先看面板底部【后端目录】：路径对不对、`start_comfy.bat` 在不在
- PS 的 UXP 日志：`%APPDATA%\Adobe\Adobe Photoshop 20XX\Logs\UXPLogs_*.log`（搜 `cleanbg`）
- 后端日志：`<后端目录>\ComfyUI\user\comfyui.log`
- 排查要按步骤来：**先确认后端目录 → 再确认后端在线 → 最后才看工作流报错**，
  否则容易被上层的误导性报错带偏（这个项目就吃过两轮亏）
