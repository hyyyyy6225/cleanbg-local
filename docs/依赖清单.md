## 三、自定义节点（放进 `ComfyUI/custom_nodes/`，6 个一个都不能少）

| 节点包 | 提供的关键节点 | 缺了会怎样 |
|---|---|---|
| `comfyui-KJNodes` | `ImageResizeKJv2`、`ColorMatch`、`PrimitiveStringMultiline` | 还原尺寸 / 颜色匹配失效 |
| `comfyui_essentials` | **`GetImageSize+`** | 提交时报 `missing_node_type: GetImageSize+` |
| `RES4LYF` | **`beta57` 采样器** | 报 `scheduler 'beta57' not in [...]`（插件会自动退回 `beta`） |
| `ComfyUI_BiRefNet_ll` | `AutoDownloadBiRefNetModel`、`GetMaskByBiRefNet` | 「自动保护人物」不可用 |
| `Comfyui-PainterFluxImageEdit` | `PainterFluxImageEdit` | 无法提交工作流 |
| `cleanbg_control`（本仓库自带） | `GET /cleanbg/ping`、`POST /cleanbg/shutdown` | 面板【关闭 ComfyUI】退化成跑脚本 |

## 四、工作流结构（供排查用）

```
19 LoadImage
90 ImageScaleToTotalPixels
91 GetImageSize+
21/22/23  CheckpointLoader(unet) / CLIPLoader(flux2) / VAELoader
24 PrimitiveStringMultiline（提示词）
25 PainterFluxImageEdit（image1_mask ← 蒙版）
26 KSampler（euler / beta57 / cfg 1.0 / 4 steps）
27 VAEDecode
30/31 4x-UltraSharp 放大
102 GetImageSize+
32/34 ImageResizeKJv2（还原到原像素尺寸）
33 ColorMatch（mkl，强度 1.0）
35 ImageCompositeMasked（用同一蒙版合成）
41 SaveImage

protect 模式额外：
60 AutoDownloadBiRefNetModel(General) → 61 GetMaskByBiRefNet → 62 GrowMask(+8)
→ 63 InvertMask → 64/65/66 蒙版尺寸对齐
```

蒙版语义：`image1_mask` 同时写进 latent 的 `noise_mask`（1 = 重绘）并用同一蒙版做合成，
所以**蒙版外 0 改动**（实测人物区最大偏差 1–2/255，>3 的像素占比 0.0000%）。
