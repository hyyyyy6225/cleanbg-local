# cleanbg-local · 「清空环境」本地模型版 Photoshop 插件

一个**完全本地运行**的 Photoshop 面板插件：把当前文档交给你自己电脑上的 ComfyUI，
用公开模型（FLUX.2 klein 9B）把画面里的路人、观众、摄影器材清掉，结果作为**新图层**放回文档。

**不登录、不联网、不花点数、不含任何加密模型。** 全程离线可用（模型另外下载一次即可）。

---

## 特点

| | |
|---|---|
| 🎯 只清背景，人物不动 | 「自动保护人物」模式用 BiRefNet 抠出人物生成蒙版，蒙版外的像素**一个都不改**（实测人物区最大偏差 1–2/255） |
| 🧩 三种处理范围 | 自动保护人物 / 整图重绘 / 仅清理 PS 选区（先在 PS 里框选，只重绘框内） |
| 📐 尺寸不缩水 | 生成后先 4 倍放大（4x-UltraSharp）再还原到**文档原始像素**，实测锐度为原图 114%–165% |
| 🎨 颜色不跑偏 | 输出经 `ColorMatch(mkl)` 把色彩统计拉回原图，平均 RGB 偏差 <0.4 |
| 🗂 后端目录自愈 | 面板里可改【后端目录】并永久记住；搬动文件夹、换盘符、换电脑都能自己找到后端 |
| 🧠 真实报错 | 启动后端只用 `shell.openPath(原生路径)`，并把返回值（成功=空字符串）原样写进日志，不用猜 |

## 系统要求

| | 最低 | 推荐 |
|---|---|---|
| 显卡 | **NVIDIA 8 GB 显存**（实测可跑；配合「快（1.8MP）」+ 4 步，速度较慢） | 16 GB 显存（RTX 5070 Ti / 4080 级别） |
| 内存 | **16 GB**（实测可跑；越大越稳） | 32 GB 以上 |
| 磁盘 | 45 GB 空闲（自动安装；模型占约 18 GB）／35 GB（便携版） | SSD |
| 系统 | Windows 10/11 64 位 | — |
| Photoshop | 2025（v26）或更新 | 2026（v27） |
| 驱动 | 较新的 NVIDIA 驱动（Turing 卡需 576+ 才能用 CUDA 12.9） | 最新 Game Ready |

> **8 GB 显存 + 16 GB 内存是实测能跑的下限**：把生成规模选「快（1.8MP）」+ 4 步，
> 单张大约 3–8 分钟（比 16 GB 显存慢，但功能完全一样）。
> ComfyUI 会自动在显存与内存之间搬模型，**不需要手动配置**；还想更省显存可以改用「整图重绘」（省掉抠人像模型的 0.85 GB）或给 ComfyUI 加 `--lowvram`。
> AMD / Intel 显卡不支持（依赖 CUDA 版 torch）。

## 安装

### 方式一：自动安装（推荐，约 20 GB 下载）

1. 下载本仓库（绿 Code → Download ZIP）并解压
2. 双击 `installer/auto/①双击我开始安装.bat`
3. 弹 UAC 点【是】；杀毒软件拦截就选【允许/信任】
4. 它会自动做完：检查电脑 → 装 VC++ 运行库 → 下载并解压 ComfyUI 便携版 →
   下载 6 个模型（国内 ModelScope / hf-mirror 直连）→ 装 6 个自定义节点 →
   装插件 + 建桌面快捷方式 + 起一次后端自检
5. 中途断了就再双击一次，已下载的部分不会重下

默认装到 `D:\ComfyUI`（没有 D 盘就 `C:\ComfyUI`），可用 `-InstallDir` 参数指定：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -InstallDir "E:\ComfyUI"
```

### 方式二：便携版（离线整包）

已经有一份别人做好的 `清空环境-便携版`（python 运行时 + ComfyUI + 模型全在里面）时：

1. 把整个文件夹拷到电脑上（路径尽量浅，如 `D:\清空环境-便携版`）
2. 双击 `installer/portable/①双击我安装插件.bat`

### 方式三：只更新插件

已经装过旧版插件、只想升级到最新版：

双击 `installer/patch/①双击更新插件.bat`
（自动找到所有已安装的 `cleanbg` 目录 → 备份 `.bak` → 覆盖 → 写后端路径 → 哈希自检）

安装完**必须重启 Photoshop**（UXP 插件只在启动时加载）。

## 使用

1. 打开要处理的照片，菜单【增效工具 / 插件】→【清空环境】
2. 面板底部确认【后端目录】是绿色（不对就点【自动查找】，或手填路径 →【应用】）
3. 点【启动 ComfyUI】，等状态变成「已就绪」（首次约 1 分钟）
4. 填提示词、选生成规模和步数，点【▶ 清空环境】
5. 结果变成名为「清空环境」的新图层 —— **不满意的地方用蒙版擦**（推荐用法）

提示词建议写得具体，例如：

```
移除画面背景中的所有路人、观众与摄影器材（灯架、柔光箱、三脚架、反光板、摄影包），
移除地面杂物与电线；严格保持人物的面部、发型、服装、饰品、姿态与原始构图完全不变；
被移除的区域用周围背景的纹理、透视关系与光照智能补全，过渡自然、无修补痕迹；
保持原有色调、明暗关系与画面噪点一致，不改变整体风格。
```

用完点【关闭 ComfyUI】释放显存；关掉 Photoshop 时看门狗也会自动关掉后端。

## 常见问题

**点【启动 ComfyUI】失败怎么办？**
面板【后端目录】下面那行会变红并写明原因；日志里会打印当前目录和真实报错。
点【自动查找】，或手动填后端文件夹路径（判据只有一个：里面有没有 `start_comfy.bat`）后点【应用】。

**安装脚本报错了？**
同目录的「安装日志.txt / 更新日志.txt」每一行都有 `[OK] / [注意] / [失败]` 标记，看 `[失败]` 那几行。

**杀毒软件报警？**
这类"自提权 + 改 Photoshop 目录 + 联网下载"的脚本很容易被误判（火绒/360 均实测误报）。
脚本内容全部公开可读，选【允许/信任】即可。

**改了插件没生效？**
改 `main.js` 后必须**重启 Photoshop**；UXP 没有热重载。

```powershell
# 3) 所有 .ps1 的 PowerShell 5.1 语法校验（应为 0 错误）
powershell -File tools/check-ps1-syntax.ps1
```

### 两个真实的坑（改代码前请先读）

1. **中文 `.ps1` 必须存成 UTF-8 with BOM。**
   PowerShell 5.1 对没有 BOM 的 UTF-8 按 ANSI(GBK) 解码，中文注释会把**整个脚本的语法拆坏**：
   实测同一个 `install-plugin.ps1`，有 BOM = 0 个语法错误，去掉 BOM = 15 个；`install.ps1` 是 109 个。
   后果很隐蔽 —— 脚本里"改路径"那一段被跳过，后面的"成功"提示照印，看起来装好了其实没改。
   因此每个 `①双击…bat` 启动器里都内联了一行"运行前补 BOM"的安全网。

2. **别再用那些"注定失败"的启动写法。**
   `fs.getEntryWithUrl()` 是存储 API、不是启动 API（拿它启动必报 `Could not find an entry of …`）；
   `openExternal("file:///…")` 自 Photoshop 22.5 起被禁（`file scheme is not supported`）。
   唯一正确：`shell.openPath(原生Windows路径)`，且**必须读返回值**（成功是空字符串）。
